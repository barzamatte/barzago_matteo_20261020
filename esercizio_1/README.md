comandi git che ho usato sono:
git commit -m "commit" che serve per documentare qualche modifica

gh repo create nome_repo --public --source=. --remote=origin --push che serve per creare la repository

git push che server per "spingere" le modifiche e salvarle

git config user.name/email serve per dare un entità propria

gh auth login per fare il login su hithub
gh auth logout per uscire dal proprio account di github
